# Principles

1. **Deterministic first.** Prefer genuine footage, explicit edit decisions, reproducible graphics, and selective generated inserts over opaque whole-video generation.
2. **Models direct; contracts carry decisions.** Use frontier models for structure, pacing, selection, and critique. Store decisions in typed data that deterministic code can inspect.
3. **Genuine subjects win.** Never synthesize a person when the source footage can accomplish the result. Lip sync or synthetic correction is a localized repair, requires explicit project permission, and retains provenance.
4. **Adapters are replaceable.** Remotion and FFmpeg are initial execution choices. Their vocabulary must not become core vocabulary.
5. **Capabilities before vendors.** Route work from requirements to declared provider capabilities. Record the selected provider only as execution provenance.
6. **Brand lives with the project.** The engine provides schemas and safe defaults, not a universal look.
7. **Reference design intelligence.** Consume pinned, approved Design Intelligence guidance. Do not reproduce its taste systems, general motion guidance, registry, or agents.
8. **Encode measurable quality.** Caption limits, generated-clip duration, attribution, timeline bounds, density, and aspect ratios are rules. Pacing and visual distinction remain review judgments until evidence supports a stable rule.
9. **Degrade loudly.** Missing design guidance, unavailable providers, failed probes, or unverified renders are explicit states.
10. **Keep Phase 1 honest.** A contract is not an integration, a render plan is not a render, and a schema-valid video is not automatically a good video.
